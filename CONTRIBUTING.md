# Contribuir

Consulta [AGENTS.md](AGENTS.md) para las reglas completas.

1. Abre un issue si el cambio es relevante.
2. Crea una rama temporal y usa Conventional Commits.
3. Abre un PR con descripción y evidencia de pruebas.
4. Tras CI verde y revisión humana, usa Squash Merge y elimina la rama.

Ejemplo: `fix(credit): correct installment rounding`.

Para cambios relevantes, vincula el issue con `Closes #N`. Las decisiones significativas se registran en docs/adr. No enviar información de clientes, secretos ni datos financieros reales.

El proyecto aún no tiene licencia de código abierto aprobada. No se presume permiso de redistribución por su visibilidad pública.
